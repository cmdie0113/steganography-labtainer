Mục tiêu học tập

  • Nắm bắt cơ chế chọn Bộ dự đoán (Predictor selection) trong chuẩn nén video VP9 (sự khác biệt giữa nearest và near).

3. Kiến thức bổ trợ

Giấu tin trên Miền dự đoán (Prediction Domain Steganography)

Trong VP9, để tiết kiệm dung lượng, luồng bitstream không lưu trực tiếp mọi Vector mà lưu "độ lệch" so với các vector lân cận đã được giải mã trước đó. Bộ mã hóa tính toán một danh sách các dự đoán. Thuật toán của chúng ta hoạt động theo nguyên tắc:

  • Gán bit 0 bằng cách ép bộ mã hóa chọn chế độ dự đoán nearest (ứng viên gần nhất).
  • Gán bit 1 bằng cách ép bộ mã hóa chọn chế độ dự đoán near (ứng viên gần tiếp theo).

Bảng tùy chọn công cụ

Công cụ Tùy chọn / Cú pháp Mô tả tác dụng
ffmpeg -hide_banner -i Kiểm tra thông tin định dạng, codec của file video đầu vào.
python3 *.py Chạy các công cụ trích xuất, nhúng vào bộ dự đoán (predictor) và giải mã thông điệp.
http.server -m http.server 1234 Khởi tạo máy chủ web nội bộ để phân phối tệp video stego.
wget http://encoder:1234/... Công cụ phía máy trạm (Decoder) để tải tệp tin từ máy chủ Encoder về máy cục bộ.

5. Các nhiệm vụ của bài thực hành

LƯU Ý QUAN TRỌNG: Quan sát kỹ dấu nhắc lệnh (prompt) để gõ đúng lệnh tương ứng vào cửa sổ encoder hoặc decoder.
Quy trình chung của bài:
Trích xuất Vector → Nhúng tin (Predictor) → Đóng gói Video → Phân phối qua HTTP → Tải & Giải mã
Nhiệm vụ 1 — Kiểm tra đầu vào video gốc MÁY ENCODER

Mục đích: Sử dụng FFmpeg để phân tích các thông số cơ bản của video gốc làm cơ sở cho các bước can thiệp.

Bước 1: Kiểm tra thông số của file video đầu vào input.webm. 

ffmpeg -hide_banner -i input.webm

Kết quả cần thấy:

Input #0, matroska,webm, from 'input.webm':
  Metadata:
    COMPATIBLE_BRANDS: isomav01iso2mp41
    MAJOR_BRAND     : isom
    MINOR_VERSION   : 512
    ENCODER         : Lavf61.7.100
  Duration: 00:00:15.71, start: -0.007000, bitrate: 19922 kb/s
    Stream #0:0: Video: vp9 (Profile 0), yuv420p(tv, bt709, progressive), 1920x1080, SAR 1:1 DAR 16:9, 30 fps, 30 tbr, 1k tbn, 1k tbc (default)
Nhiệm vụ 2 — Trích xuất dữ liệu Motion Vector MÁY ENCODER

Mục đích: Bóc tách luồng khung hình, đánh giá các bộ dự đoán và lưu mảng JSON chứa các `candidates` vào file mv_candidates.json.

Bước 1: Đọc mã nguồn của script trích xuất để hiểu cách hệ thống bóc tách dữ liệu VP9. 

cat vp9_extractor.py

Bước 2: Chạy script để trích xuất các vector chuyển động từ file video. 

python3 vp9_extractor.py

Kết quả cần thấy:

[+] Extracting VP9 motion vector predictors...
[+] Extracted [Số_lượng] predictor candidates
[+] Saved to mv_candidates.json
Nhiệm vụ 3 — Nhúng thông điệp (Encode) MÁY ENCODER

Mục đích: Máy sẽ đọc thông điệp từ secret.py, chuyển thành chuỗi nhị phân, và ánh xạ từng bit này vào việc lựa chọn tham số predictor (giữa nearest và near), xuất file cấu hình mv_choices.json.

Bước 1: Xem mã nguồn thuật toán để nắm rõ logic can thiệp vào Predictor Mode. 

cat encode.py

Bước 2: Tiến hành nhúng thông điệp

python3 encode.py

Kết quả cần thấy:

[+] Embedded 88 bits
[+] Output saved to mv_choices.json
Nhiệm vụ 4 — Đóng gói Video (Repack) MÁY ENCODER

Mục đích: Lồng ghép phụ lục danh sách quyết định dự đoán (mv_choices.json) vào định dạng file WebM để tạo file thành phẩm.

Bước 1: Đọc mã nguồn tái cấu trúc video.

cat repack_video.py

Bước 2: Đóng gói lại trở lại thành một file video stego hoàn chỉnh (stego_video.webm). 

python3 repack_video.py

Kết quả cần thấy:

[+] Repacking VP9 stego video...
[+] Stego video created
[+] Output: stego_video_dir.webm
Nhiệm vụ 5 - Thiết lập cổng phân phối HTTP MÁY ENCODER

Mục đích: Khởi tạo nền tảng Web Server đơn giản trên cổng TCP 1234 nhằm phục vụ việc tải tệp.

Bước 1: Gửi video lên Web Server đơn giản trên cổng 1234. 

python3 -m http.server 1234

Kết quả cần thấy:

Serving HTTP on 0.0.0.0 port 1234 (http://0.0.0.0:1234/) ...
Nhiệm vụ 6 — Tải tệp ẩn mã qua đường truyền IP MÁY DECODER

Mục đích: Kết nối qua Socket, đóng vai trò Client nhận tệp video từ máy chủ trung tâm. 

wget http://encoder:1234/stego_video_dir.webm
Nhiệm vụ 7 — Dịch ngược thông điệp từ Miền Dự đoán MÁY DECODER

Mục đích: Phân tích siêu dữ liệu đính kèm, ánh xạ ngược từ trạng thái bộ dự đoán (nearest -> 0, near -> 1) thành chuỗi bit và khôi phục văn bản.

Bước 1: Kiểm tra thuật toán giải mã.

cat decode.py

Bước 2: Tiến hành giải mã dữ liệu và lưu kết quả đầu ra vào file decode.stdout. 

python3 decode.py > decode.stdout

Kết quả cần thấy:

(Không có thông báo hiển thị trên màn hình do output đã được chuyển hướng vào file decode.stdout)
Nhiệm vụ 8 — Kiểm tra độ vẹn toàn dữ liệu MÁY DECODER

Mục đích: Xem nội dung đã được giải nén để đối chiếu với thông điệp gốc. 

cat decode.stdout

Kết quả cần thấy:

[+] Hidden message recovered:
ATTTD22PTIT

6. Kiểm tra kết quả bài thực hành

Sử dụng cửa sổ Terminal (hoặc dừng server cục bộ) và chạy lệnh đánh giá: 

checkwork vp9-mv-predictor-steg

Kết quả kỳ vọng: Tích xanh Y hoàn thành toàn bộ chỉ tiêu.

Checkwork Máy thực hiện Ý nghĩa
check_info Encoder Đã gọi lệnh kiểm tra thông số banner -i input.webm.
run_extractor Encoder Ghi nhận việc chạy mã nguồn on3 vp9_extractor.py thành công.
run_encoder Encoder Xác nhận script python3 encode.py đã nhúng mã ngầm vào file json.
run_repack Encoder Thực thi đóng gói video on3 repack_video.py.
run_server Encoder Kích hoạt thành công cổng Host 3 -m http.server 1234.
run_download Decoder Phát hiện truy vấn wget lưu file xuống máy trạm.
run_decoder Decoder Tiến hành khôi phục e.py > decode.stdout.
found_secret Decoder Dịch ngược thành công chuỗi mật mã ATTTD22PTIT.
